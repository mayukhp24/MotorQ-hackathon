# Declarations

## Data

All data in this repository and in the demo is **synthetic**, generated by
`services/pipeline/internal/sim` from a fixed seed: tenants, depots, 100,000
vehicles (VINs with valid check digits under three fictitious manufacturer
codes), 80,000 drivers (generated names, licence and phone numbers), telemetry,
faults, breakdowns and service history. No real personal data, vehicle data or
customer data is used. The fault-code knowledge base is written for this
project from general, publicly documented OBD-II code meanings.

## AI tools used

| Tool | Used for |
|---|---|
| Claude Code (AI coding assistant) | Pair-programming across the repository: code, tests, infrastructure, documentation and this solution document, under the team's direction and review |
| LLM API (runtime, optional) | The maintenance copilot's reasoning and tool use: any OpenAI-compatible provider the operator configures (e.g. a free Groq or Gemini tier, or a local Ollama model) or Claude; without one, the offline planner answers |
